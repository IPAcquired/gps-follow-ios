Reading the Pi's upstream Wi-Fi connection…

The ESP32 stays on Drone-Display. Only the Orange Pi joins your iPhone hotspot or another saved, secure network.

  1. For an iPhone hotspot, open Settings → Personal Hotspot. Enable Maximize Compatibility and Allow Others to Join.
  2. Use the exact phone name from Settings → General → About → Name.
  3. Save the name and password here. Saving alone preserves the current connection.
  4. Tap Connect to selected network. Leave the hotspot Settings screen open while the Pi joins. If this page loses contact, rejoin Drone-Display and reopen the app.

Changing Wi-Fi waits for safe flight status. Reading this dashboard does not require the H743 to be connected. No open network is automatically added.

Your field checklist

Download the step-by-step guide (PDF)

1 · Save this app before going out
  1. Connect the iPhone to the same network as the Pi, or join Drone-Display with your private Wi-Fi QR.
  2. Open the private HTTPS field link. Keep the AXL certificate installed and trusted.
  3. In Safari, tap Share → Add to Home Screen. Enable Open as Web App if shown, then tap Add.
  4. Open the PDF above and choose Share → Save to Files → On My iPhone. The instructions remain available without internet.
  5. Keep the private setup card separately. The public guide contains no passwords or access keys.
2 · Connect in the field
  1. Power the Pi and ESP32. Allow about a minute for startup. The H743 may remain disconnected for network setup.
  2. For a saved hotspot, enable Maximize Compatibility and Allow Others to Join on the iPhone. Leave Settings open while the Pi joins.
  3. If no saved network is available, join Drone-Display, open this app and add a secure network under Connect.
  4. Review the current network. Confirm Pi data is fresh and the ESP32 reports an authenticated Pi connection.
  5. For phone GPS, open your separate private GPS link, allow Location, tap Start sharing and keep Safari visible. Screen-awake mode cannot enable background GPS.
3 · Updates and safe shutdown

Having internet does not automatically authorize every update. The existing automatic updater is restricted to its configured home network and eligible Debian security updates. Board drivers, AI runtime changes and H743 firmware need a compatible reviewed release. The hotspot page does not bypass those rules.

Use the ESP32’s safe storage/unmount and power options before removing its SD card. Do not remove the Pi’s SD card while it is running. Verify flight readiness separately on the controller; this page is advisory.

4 · If it does not connect
  • Enable Maximize Compatibility; recheck the exact phone name, including apostrophes, and password.
  • Leave the hotspot Settings screen open. A 5 GHz association rejection is different from a wrong password.
  • Use Drone-Display for setup without internet. “No Internet Connection” on that local network is expected.
  • If iPhone does not show a setup prompt, open AXL Field yourself. iOS controls whether the network prompt appears.
  • If a certificate warning appears, do not bypass it. Confirm the hostname is example-pi.local and the installed AXL certificate is trusted and unexpired.
  • Reopen the private field link if the app asks to unlock after a Pi service restart or after seven days.

Local data stays on your devices. No third-party scripts, analytics or public telemetry relay. Desktop owner access gives control of the Pi session.
